llm-inspect

LLM アプリケーションの入力と出力を検査する Rust ライブラリのデモです。処理はすべてブラウザ内の WebAssembly で行われ、入力したテキストはどこにも送信されません。 GitHub

検出は完全ではありません。パターン照合では捕捉できない攻撃や個人情報があり、誤検知も起こります。多層防御の一層として使う前提のライブラリです。
